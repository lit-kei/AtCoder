# ABC251 D — At Most 3 (Contestant ver.)

- 問題: https://atcoder.jp/contests/abc251/tasks/abc251_d
- 状況: 最終構築コードを完成（提出結果のAC報告は未確認）
- コード: [main.cpp](main.cpp)
- 手法: 100進法による構築

## 解法

おもりを次の300個とする。

- 1, 2, ..., 100
- 100, 200, ..., 10000
- 10000, 20000, ..., 1000000

任意の 1 <= x < 1000000 は、100進法で
`x = a + 100*b + 10000*c`（0 <= a,b,c <= 99）と書ける。
0の項を選ばなければ最大3個の異なるおもりの和として表せる。
1000000は最後のおもり1個で表せる。
したがって入力Wがいくつであっても、300個の固定の構築で条件を満たせる。

## 計算量

300個の数を出力するだけなので、時間・追加空間は O(1)（出力数は定数）。

## 振り返り（自力・解説参考）

**自力**: 当初は、おもりを1個ずつ増やし、3個以下の和で表せる連続範囲を全探索する構築を試した。探索が非常に重くなり、方針に難しさを感じた。

**対話で得た発想**: 「3個以下」と「100進法の3桁」を対応させ、3つの位にそれぞれ100個の候補を用意する構築を教わった。最終コードはその規則を利用して作成した。

学び: 構築問題では、探索で候補を決めるよりも、全条件を保証する数の表現・規則を発見する方が簡単なことがある。
