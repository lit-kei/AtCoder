# ABC245 D — Polynomial division

- 問題: https://atcoder.jp/contests/abc245/tasks/abc245_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 多項式の筆算・最高次からの係数決定

## 解法

多項式 `A(x) B(x) = C(x)` で、A と C の係数が与えられており B の係数を求める。
A は N 次、B は M 次で、最高次の係数 A[N] は0でない。
最高次の係数から `C[N+M] = A[N] * B[M]` なので、`B[M] = C[N+M]/A[N]` と確定する。

その後、`B[M] * x^M * A(x)` の各係数への寄与を C から引けば、残る多項式の次数が下がり、同じ操作で B[M-1] を求められる。

本人の実装:
```cpp
drep(i, M+1) {
    ll q = C[i+N] / A[N];
    B[i] = q;
    rep(j, N+1) {
        C[i+j] -= q * A[j];
    }
}
```

## 正当性

i を大きい順に進める。i の処理開始時点で、既に確定した B[j] (j>i) の寄与は C から引かれている。
したがって、残る最高次 `N+i` の係数は `A[N]*B[i]` だけで、割り算により B[i] が確定する。
その寄与を全次数から引けば同じ不変条件を次の i に引き継ぐ。
問題では整数係数の B が存在することが保証されるため、割り算も正確に行える。

## 計算量

外側が M+1 回、内側が N+1 回。
時間 **O((N+1)(M+1))**、配列の空間 **O(N+M)**。

## 自力と振り返り

**完全自力AC**。最高次から商を求め、確定した項の寄与を多項式 C から引いていくアルゴリズムを本人が独力で実装した。
一般の多項式の筆算と同じ手順であり、高い次数から未知の係数を確定する後退代入に近い構造を持つ。
