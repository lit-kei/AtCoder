# ABC218 D — Rectangles

- 問題: https://atcoder.jp/contests/abc218/tasks/abc218_d
- 判定: **AC**（本人確認）
- 言語: C++23（`set::contains` 使用）
- 計算量: **O(N² log N)**、空間 **O(N)**

## 解法

座標の集合 `set<pair<ll,ll>> S` と、入力点を列挙する `vector<pair<ll,ll>> P` を用意する。

異なる2点 `(x1,y1)`, `(x2,y2)` を全探索し、`x1 != x2` かつ `y1 != y2` なら長方形の対角頂点の候補となる。残りの2点 `(x1,y2)`, `(x2,y1)` が集合に存在する場合に数える。

同じ長方形は2本の対角線によって **2回** 数えられるため、最後に `cnt / 2` を出力する。

点の組の列挙が O(N²)、各存在判定が O(log N)。座標自体が大きくても、保持するのは実在する N 点だけ。

## 考察の過程（自力とヒントを区別）

### 自力で考えたこと
- 4点全探索 O(N⁴) は不可能。
- 同じ y 座標の点を組にして調べる方針を発想した。
- 座標が大きく、長さ L の配列で直接管理するのは難しいと認識した。
- ただし、具体的なデータ構造や実装に至らなかった。

### ヒントを受けたこと
- 対角頂点2つを固定すると残りの2点が一意に決まる、という着眼点。
- 座標集合を `set<pair<ll,ll>>` に保存して存在判定をする方法。

### 自力で実装したこと
- 2点を選ぶ二重ループ。
- 同じ x または同じ y の除外。
- `S.contains({x1,y2}) && S.contains({x2,y1})` の判定。
- 2本の対角線による重複カウントを `cnt / 2` で補正。

## 振り返り

今回の課題は実装ではなく、**少数の要素を固定すると残りが決まるか**という発想。自力で同じ y 座標の点に注目した方針も正解につながるので、初期発想自体は評価できる。次回は「何を固定すれば残りが一意に決まるか」を早い段階で検討する。
