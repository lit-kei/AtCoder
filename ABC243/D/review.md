# ABC243 D — Moves on Binary Tree

- 問題: https://atcoder.jp/contests/abc243/tasks/abc243_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 二進数による根からの経路の管理

## 発想

整数の頂点番号そのものに `U/L/R` 操作を適用すると、最終的な結果が範囲内でも途中で大きくなりオーバーフローする可能性があると気づいた。
二分木の頂点 x は、根1からの左右移動の列として表現できる。
- L: x→2x。二進表記の末尾に0を追加
- R: x→2x+1。二進表記の末尾に1を追加
- U: x→floor(x/2)。末尾の1ビットを削除

初期 X を2で割りつつ余りを `deque<bool> path` の先頭に挿入し、根からの移動経路を作る。
Sの各操作について L/R なら末尾に 0/1 を追加、U なら末尾を削除する。
最後に1から始め、`ans=(ans<<1)+path.front()` として元の頂点番号を復元する。

## 正当性

二分木の番号付けと、末尾へのビット追加・削除が各操作に一致している。
したがって、操作列を処理した後の `path` は現在の頂点への根からの経路を表す。
経路を最初からたどれば、求める最終頂点が得られる。
U 操作は問題で合法な移動として与えられる（根より上へ移動しない）ことを前提に、`pop_back` で実装できる。

## 計算量

初期 X の二進数桁数を B とすると、初期化と各操作・復元を合わせて時間 O(N+B)、空間 O(N+B)。
頂点番号ではなく経路を保存するので、中間状態の整数オーバーフローが起きない。

## 自力と振り返り

**完全自力AC。** オーバーフローの可能性に気づき、根からの経路を左右の真偽値として保存する発想と `deque<bool>` の実装、復元まで本人が独力で行った。
同様の表現は `string` に0/1を追加する方法でも実装できる。
