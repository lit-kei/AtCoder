# ABC238 D — AND and SUM

- 問題: https://atcoder.jp/contests/abc238/tasks/abc238_d
- 結果: **自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: AND/XOR/加算の関係とビット判定

## 着想と必要十分条件

非負整数 x, y に対して、二進数の各桁ごとに
`x+y=(x^y)+2*(x&y)` が成り立つ。
求める条件は `x&y=a`, `x+y=s` なので、`b=s-2*a=x^y` と置ける。
b が負なら不可能。また、AND と XOR で同じ位置に同時にビットが立つことはないため、`(a&b)==0` が必要。

実はこれで十分でもある。b>=0 かつ (a&b)==0 なら `x=a`, `y=a+b` と取ると、`a&(a+b)=a`、`a+(a+b)=s` を満たす。

すなわち判定条件は

```cpp
ll b = s - 2*a;
bool ok = (b >= 0 && (a & b) == 0);
```

## 本人の実装

`help(n)` で2進表現の桁数を求め、`bit[j]` に a の j ビット目が1かを記録。
`rest=s-a-a` が負なら No。
それ以外は rest のビットが立っている位置で、同じ位置の a のビットも立っていないか調べている。
これは上記の `(a&rest)==0` と同値で、正しい。

## 計算量

各テストケースで2進数の桁数を d とすると、`help` と各ビットの確認は O(d)。
T ケース全体で **O(T log V)**（V は入力値の大きさの代表値）、補助空間 O(log V)。
long long は高々64ビットなので、実際には小さな定数時間・空間で処理できる。

## 自力・振り返り

**完全自力AC。** `rest=s-2a`、負なら不可能、rest と a で同じビットが立つ場合は不可能という判定を自分で導いて実装した。
AC後の対話で `x+y=(x^y)+2*(x&y)` の恒等式と十分性の証明を整理した。
また、ビット列を用意して1ビットずつ調べる代わりに `(a&rest)==0` の1回の演算に簡潔化できると確認した。

備考: `if ((rest >> j) & 1 && bit[j])` は演算子優先順位の関係で動くが、`if (((rest >> j)&1LL) && bit[j])` と括弧を足すと読みやすい。
