# ABC239 D — Prime Sum Game

- 問題: https://atcoder.jp/contests/abc239/tasks/abc239_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: エラトステネスの篩 + 二重全探索（量化条件）

## 解法

高橋は x を [A,B] から選び、青木はその後 y を [C,D] から選ぶ。
高橋が勝つ条件は **ある x が存在して、どの y に対しても x+y が素数にならない**こと。

```text
exists x in [A,B] such that
    for all y in [C,D], x+y is not prime
```

まず `mx=B+D` までエラトステネスの篩で素数判定を前計算する。
高橋の候補 x を全探索し、青木が素数和にできる y を一つでも持つかを調べる。
一つもなければ Takahashi、どの x に対しても青木が素数和を実現できれば Aoki。

## 篩の補足

本人の `nfor(j, 2, (mx+i)/i)` は、整数演算により `j*i <= mx` を満たす j>=2 をちょうど列挙する。
`prime` ベクトルは回答判定に使わず、不要なので削除できる。
`furui[0]` と `furui[1]` は true のままだが、この問題で取り得る和は2以上なので影響しない。

## 計算量

`M=B+D`。
篩は O(M log log M)、勝敗判定の全探索は O((B-A+1)(D-C+1))。
時間 **O(M log log M + (B-A+1)(D-C+1))**、空間 **O(M)**。

## 自力と振り返り

**完全自力AC**。素数判定の篩、後手の全候補をチェックする二重ループ、早期 break の処理を本人が実装。
「高々10^4程度の全探索で間に合う。複雑な実装をするより簡単な実装を選ぶ」という本人の判断が今回の重要な成果。
先手は存在条件（ある x）、後手は全称条件（すべての y を防げる）の違いをコードに落とし込めている。
