【第1版】
C問題と似てる
個数だけでいいのがポイント。
A[i+1] == A[i] みたいな箇所が連続していれば、そこのカウントだけ考えればよい。
ans=1で初期化し、前にしか挿入できないと考えてよい。
nC2+1通りから、いくつかぶりがあるかを前から見ていく。
eを追加するとき、これまでのeの出現回数を引けばよい。
実装したが 1 2 2 2 2 で計算が合わない。

第1版の主要部分:
ll ans = nc2(N) + 1;
rep(i, N) {
    ll e; cin >> e; e--;
    ans -= cnt[e];
    cnt[e]++;
}

【第2版＝最終AC】
サンプルが通らない。
適当に作った 1 2 2 2 2 で計算が合わない。
同じ数が連続するとき、それを先頭に入れることを考える必要がある。
同じ数が連続したらans--とか？
今まさに自分自身が連続している区間に入っているときの計算方法に間違いがありそう
1 2 2 3 3でも合わない。

最終補正:
ans -= cnt[e];
cnt[e]++;
if (i >= 1 && A[i] == A[i-1]) {
    row++;
    ans += cnt[e] - 1;
    ans -= i;
} else {
    row = 1;
}

補正は本人が数学的に導いた。
ACコードは第2版と同一。

【得られた学び】
- 重複を引く数え上げ
- 自作反例で誤りを発見
- 同値要素の連続を考慮した補正
- O(N) 解法でAC
