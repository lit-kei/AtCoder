# ABC484 D — 振り返り

- [問題](https://atcoder.jp/contests/abc484/tasks/abc484_d)
- [AC提出](https://atcoder.jp/contests/abc484/submissions/80843356)
- 400点、52:23 AC（Cから25:57）

## 着想

C問題に似た要素の移動操作。異なる結果の個数を数える。
後ろから前へ要素を移動する (l,r), l<r の候補は N(N-1)/2 組で、元の配列も合わせて 1+N(N-1)/2 通り。重複を除く。

## 第1版

左から読んで、同じ値の過去出現回数 cnt[e] をその都度引いた。
これは 1 + C(N,2) - Σ_x C(c_x,2) を計算している。
しかし、1 2 2 2 2、1 2 2 3 3 といった自作反例で数え方が合わなかった。

## 最終AC版

過去の同値出現回数を引きつつ、隣接する値が等しいときに補正する。

~~~cpp
ans -= cnt[e];
cnt[e]++;
if (i >= 1 && A[i] == A[i-1]) {
    row++;
    ans += cnt[e] - 1;
    ans -= i;
} else {
    row = 1;
}
~~~

0-indexed の i において A[i]==A[i-1] なら上記の変化量は -cnt[e]+(cnt[e]-1)-i = -(i+1)。元の候補 i 個の扱いを打ち消し、重複分もさらに1つ引いている。異なる場合は、先行する同値要素の出現回数を引く。

## 計算量

- 時間 O(N)
- 空間 O(N): 入力配列と値別出現回数

## レビュー

- 組合せ総数から重複を差し引く方針が明快。
- 反例を自作し、連続する同値要素を手掛かりに数学的に補正を導出した点が重要。
- row は更新しているが、答えには使われないため削除可能。
- cnt のコメントは「値 e に対応する出現回数」と明記するとよい。
- 値3種類、長さ1〜8の全9840配列について、要素を後ろから前へ移動した結果の set のサイズと式を独立比較し、不一致なし（検証は証明の代替ではない）。
