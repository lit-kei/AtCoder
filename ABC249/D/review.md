# ABC249 D — Index Trio

- 問題: https://atcoder.jp/contests/abc249/tasks/abc249_d
- 結果: **AC（解説を参考にして実装）**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 値の出現頻度、積の列挙、調和級数型の計算量

## 自力で考えたこと

条件を `A_i = A_j * A_k` と書き換え、素朴な O(N^3) が不可能なため、ソートと二重ループで探索空間を減らすことを考えた。
しかし最初の実装は異なる添字の順序を制限しすぎたり、同じ値の個数・同じ添字の使用を正しく数えられなかった。
問題では i,j,k は同じ添字でもよい。

## 解説で理解した解法

値 x の出現回数を `cnt[x]` とする。
`A_j=x, A_k=y, A_i=xy` を満たす順序付き添字の三つ組は `cnt[x]*cnt[y]*cnt[x*y]` 通り。
値の上限を M とすると、積 x*y が M 以下の組のみを調べればよい。

```cpp
for (ll x = 1; x <= M; x++) {
    for (ll y = 1; x * y <= M; y++) {
        ans += cnt[x] * cnt[y] * cnt[x * y];
    }
}
```

x と y は順序付きなので入れ替えた組も数える。x=1 の場合を含めることが重要（A_i に 1 があり得る）。本人はこの理由を確認問題で正しく答えた。

## 計算量

x 固定時の y の候補は `floor(M/x)` 個。
従って総反復回数は

```math
\sum_{x=1}^{M}\left\lfloor\frac{M}{x}\right\rfloor = O(M\log M)
```

である。入力 O(N)、時間 **O(N + M log M)**、空間 **O(M)**。
ただし、上限 M=200000 を定数として使う。
