# ABC247 D — Cylinder

- 問題: https://atcoder.jp/contests/abc247/tasks/abc247_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: queueによる同値要素のまとめ管理、償却計算量

## 解法

ボールを1個ずつ保持せず、連続して追加した同じ値のボールを `{個数, 値}` のペアとしてキューに積む。
`queue<pair<ll,ll>> q` を使い、先頭から取り出す操作をそのまま表現した。

- タイプ1 `1 x c`: `q.push({c,x})`。
- タイプ2 `2 c`: 先頭のまとまりの個数が残りの取り出し数以下なら、そのまとまり全部の値を和に加え、残数を減らして `pop()` する。それより少数だけ取り出す場合は、そのまとまりの個数を減らして終了する。

## 正当性

キューの各ペアが筒内のボールを先頭から順に表しているという不変条件を保つ。
タイプ1は末尾に c 個の x を追加するので正しい。タイプ2は先頭から指定数だけ取り出し、完全に取り出したペアだけ削除し、部分的に残るペアの個数を更新するので、取り出した値の総和も残りの状態も正しく表せる。

## 計算量

1回のタイプ2では while が複数回動くことがあるが、各ループは「ペアを pop して消費する」か「c=0 として処理を終える」かのどちらか。
各ペアは高々1回 push、1回 pop されるため、全クエリを通じた pop の回数は高々 Q。
したがって償却解析で **時間 O(Q)**、補助空間 **O(Q)**。
