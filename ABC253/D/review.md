# ABC253 D — FizzBuzz Sum Hard

- 手法: 等差数列の和、包除原理、最小公倍数

## 解法

1から N までの整数の和は N(N+1)/2。
A の倍数の和と B の倍数の和を引き、重複して引いた `lcm(A,B)` の倍数の和を足し戻す。

d の倍数の総和は `m=floor(N/d)` として

```text
d + 2d + ... + md = d*m*(m+1)/2
```

で求まる。

本人のコードでは `nc2(N+1)` で全体の和を、`calc(d)=d*nc2(N/d+1)` で d の倍数の和を求め、

```cpp
ll L = lcm(A, B);
cout << nc2(N+1) - (calc(A) + calc(B) - calc(L));
```

とする。

## 正当性

各整数 k は、A,B のどちらでも割り切れなければ1回加算されたまま。
ちょうど一方の倍数なら、その倍数和で1回引かれて0回。
両方の倍数なら1回加算、2回減算、最小公倍数の倍数和で1回加算され0回。
したがって条件を満たす整数の和に一致する。

## 計算量

`std::lcm` 内部で最大公約数を計算するため時間 O(log min(A,B))、追加空間 O(1)。
