# ABC486 B — 選手交代のシミュレーション

- [問題](https://atcoder.jp/contests/abc486/tasks/abc486_b)
- [AC提出](https://atcoder.jp/contests/abc486/submissions/81124275)
- 結果：**AC / 200点 / 3:28 / WAなし**
- [main.cpp](main.cpp)：本人が共有した最終ACコード

## 解法

現在試合に出場している選手の背番号を `set<ll> S` で管理する。

最初の `N` 人の背番号から集合を作り、`M` 回の交代 `(x, y)` を順に処理する。

- 退場する選手 `x` を `S.erase(x)` で削除する。
- 出場する選手 `y` を `S.insert(y)` で追加する。

最後に集合を先頭から走査して背番号を出力する。C++ の `set` は要素を昇順に保持するため、並べ替えの処理は不要。

## 計算量

現在の人数が常に `N` 人であるため、各交代の削除・挿入はそれぞれ `O(log N)`。

- 初期集合の構築：`O(N log N)`
- `M` 回の交代：`O(M log N)`
- 出力：`O(N)`
- 合計時間：**O((N+M) log N)**（`N >= 2` を想定した表記）
- 空間：**O(N)**

## コードレビュー

- 現在出場している背番号の集合だけ持てば十分という整理ができている。
- `set` により、出場状態の管理と昇順出力を一つのデータ構造で実現している。
- 問題の交代条件で `x` は出場中、`y` は控えなので、削除と追加をそのまま適用してよい。
- 出力末尾の空白はこの提出で受理されている。
- ほかの手法として配列や `unordered_set` で管理して最後にソートする方法もあるが、今回の `set` は簡潔。
