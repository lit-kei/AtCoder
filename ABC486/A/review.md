# ABC486 A — A/B/C を Alpha/Bravo/Charlie に変換

- [問題文](https://atcoder.jp/contests/abc486/tasks/abc486_a)
- [AC提出](https://atcoder.jp/contests/abc486/submissions/81121574)
- **結果：AC / 100点 / 1:58 / WAなし**
- [main.cpp](main.cpp)：コンテスト中のACコード（本人提供）

## 解法

長さ `N` の文字列 `S` を左から順に走査し、各文字を次のルールで出力する。

- `A` → `Alpha`
- `B` → `Bravo`
- `C` → `Charlie`

入力文字が `A`、`B`、`C` のいずれかであることが保証されるため、最後は `else` で `C` を処理してよい。

## 計算量

- 時間：**O(N)** — 各文字を1回ずつ処理する。
- 追加空間：**O(1)** — 入力文字列 `S` の保持を除く。

## コードレビュー

- 条件分岐が問題の指定と一対一に対応していて、簡潔で正しい。
- `cout << "Alpha ";` のように最後の単語の後にも空白を出すが、AtCoderで一般的な空白区切りの出力として受理されている。
- 不要なテンプレート部分はあるが、コンテストで普段使うテンプレートとしてそのまま保存した。
