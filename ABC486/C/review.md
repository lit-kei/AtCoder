# ABC486 C — ランプの点灯操作

## 解法

1回の操作で点灯する位置は、開始位置 `i` から `i+K, i+2K, ...` と等間隔に続く。すでに点灯しているランプを再び点灯してもよいが、最終状態で `.` の位置を点灯させてはいけない。

したがって、位置を `K` ずつ進めたとき、`o` が連続している区間（`K` 間隔の連結成分）ごとに1回の操作が必要で、1回で十分。

### 実装

- `i = 0 .. N-1` を左から走査。
- `S[i] == '.'`、または `visited[i]` なら何もしない。
- まだ処理していない `o` なら、そこで新しい操作を開始すると考え、`cnt++`。
- `i+K, i+2K, ...` にある連続した `o` を `visited` にし、`.` で打ち切る。

各操作は同じ `K` 間隔の連続した `o` 全体を覆える。他の操作で途中の `.` を飛び越えることはできないため、各連結区間には必ず1回以上の操作が必要。この方法で最小回数になる。

## 計算量

- 時間：**O(N)**。外側の走査は `N` 回。内側で `o` を訪問済みにする処理は各位置につき高々1回で、`.` を検出して終了する回数も操作開始回数以下であるため、全体で `O(N)`。
- 空間：**O(N)**。 `visited` 配列を使用。

## コードレビュー

- `visited` によって、同じ連続区間を何度も数えない設計が明快。
- `S[j] == '.'` で即座に打ち切ることが重要。消灯位置を含む1回の操作はできない。
- 実は `visited` を使わず、各 `o` について `i-K < 0` または `S[i-K] == '.'` の場合だけ数える実装でも `O(N)` で解ける。これは**改善案**であり、保存したACコードには変更を加えない。
