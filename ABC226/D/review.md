# ABC226 D — Teleportation

- 問題: https://atcoder.jp/contests/abc226/tasks/abc226_d
- 結果: **自力AC**（本人確認）
- ソース: [main.cpp](main.cpp)

## 解法

すべての順序付き都市ペア (i,j), i≠j に対し、移動ベクトル (dx,dy)=(x_j-x_i,y_j-y_i) を作る。
`g=gcd(dx,dy)` で両成分を割り、既約な整数ベクトル `(dx/g,dy/g)` を `set<pair<ll,ll>>` に入れる。
異なる既約ベクトルの種類数が必要な魔法の種類数。

同じ方向への正整数倍の移動は同じ魔法で実現でき、逆方向は別の魔法が必要。
例えば (6,9),(2,3) はともに (2,3) に正規化され、(-4,-6) は (-2,-3) になる。
ベクトルの成分は負や0もあり得るため、「互いに素な自然数の組」ではなく `gcd(|dx|,|dy|)=1` を満たす整数の組と表現するのが正確。
都市の座標は互いに異なるので (dx,dy)=(0,0) は起こらず、g=0 の除算は起きない。

## 計算量

全都市ペアは O(N²) 個。
各ペアの `gcd` は座標差の上限 C に対して O(log C)、`set` の挿入は O(log N)。
合計時間 **O(N²(log N + log C))**、追加空間 **O(N²)**。

## 振り返り

**完全自力AC。** 移動方向の本質はベクトルの正整数倍を同一視することと見抜き、整数の最大公約数で正規化した。
傾きや角度など浮動小数点で比較すると垂直方向の例外や精度誤差があるが、整数ペアなら厳密に比較できる。
数学的な本質をとらえた結果、実装は簡潔で安定した。
