# ABC255 D — ±1 Operation 2

- 問題: https://atcoder.jp/contests/abc255/tasks/abc255_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: ソート、累積和、二分探索

## 方針

クエリ X について、必要な操作回数は `sum_i |A[i]-X|`。
配列 A を昇順ソートし、`rui[k]=A[0]+...+A[k-1]` を前計算する。
`n=lower_bound(A.begin(),A.end(),X)-A.begin()` とすれば、前半 n 個は X 未満、残り N-n 個は X 以上。

```cpp
ll ans = rui[N] - rui[n] - (N-n)*X;
ans += n*X - rui[n];
```

前半の和は `n*X-rui[n]`、後半の和は `rui[N]-rui[n]-(N-n)*X` となり、その和が答え。

## 正当性

各要素について X より小さいときの差は `X-A[i]`、X 以上のときの差は `A[i]-X`。昇順で境界を二分探索すると各群は連続区間となり、累積和で両群の寄与を正確に計算できる。

## upper_bound にしてもよい理由

本人のコメント「upper_boundにしても変わらない？」はその通り。
X と等しい要素は絶対値への寄与が 0 なので、`lower_bound` と `upper_bound` のどちらで群を分けても答えは変わらない。

## 尺取りについて

本人のコメントでは尺取りによる高速化も検討されていた。
クエリ X が昇順なら境界を一方向に動かせるが、一般にはクエリが任意順なので、オフラインソートと回答順の復元が必要。
現コードの独立した二分探索は簡潔で十分高速。

## 計算量

配列のソート O(N log N)、累積和 O(N)、各クエリの境界探索 O(log N)、値の計算 O(1)。
全体 **O(N log N + Q log N)**、補助空間 **O(N)**。
