# ABC228 D — Linear Probing

- 問題: https://atcoder.jp/contests/abc228/tasks/abc228_d
- 結果: **AC**（本人確認）
- 最終コード: [main.cpp](main.cpp)
- 手法: `set` + `lower_bound`

## 解法

長さ M=2^20 の配列を -1 で初期化し、空いている添字を `set<ll> unused` で管理する。

タイプ1 (`1 x`): まず `h=x%M`。未使用添字の中で h 以上の最小を `lower_bound(h)` で見つける。存在しないときは先頭 `*unused.begin()` を使う。そこに**元の入力値 x**を保存して、未使用集合から削除する。

タイプ2 (`2 x`): `array[x%M]` をそのまま出力。

未使用添字だけを set に保つので、連続する使用済み要素を毎回1個ずつ調べる必要がない。操作1の挿入場所の選び方は、配列を円環状に巡回して最初に空きを見つける操作と一致する。

## 計算量

初期化が O(M log M)、タイプ1が O(log M)、タイプ2が O(1)。
全体の時間 **O(M log M + Q log M)**、空間 **O(M)**。

## 自力・ヒント

**自力:** 空き添字を set で管理する設計、`lower_bound` による次の未使用位置の探索、最後まで見つからないときに `begin()` へ戻る処理、使用後の `erase`。

**修正時のヒント:** 最初の提出前コードは入力値 x を1減らす癖があり、さらに h を `x%M` とせず `lower_bound(x)` を使っていた。対話で x は値そのもので0-index補正は不要、添字にだけ剰余を使うべきと指摘され、修正してAC。

## 振り返り

状態を表すキーが配列の添字か入力値そのものかを見極めることが大切。構造としては初回から正しい。
別解にはUnion-Findなどを用いて次の空き位置を管理する方法がある。
