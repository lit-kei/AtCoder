# ABC235 D — Multiply and Rotate

- 問題: https://atcoder.jp/contests/abc235/tasks/abc235_d
- 結果: **自力AC**（本人確認）
- 最終コード: [main.cpp](main.cpp)
- 手法: 整数を頂点とするBFS（状態空間探索）

## 解法

状態を現在の整数 e とし、初期状態 1 から次の2操作を辺としてBFSする。
1. a 倍する。
2. 10以上かつ末尾が0でないとき、末尾の数字を先頭に移動する。

各操作は1回として数えられるため、BFSの初回到達時の距離が最短回数。`dest[n]` を -1 で初期化し、未訪問チェックと距離を兼ねる。
目標 N の桁数を d として、探索する値を `10^d-1` 以下に制限する。掛け算で桁数を増やした状態は元の桁数へ戻せず、回転は桁数を変えないので、目標に至る経路には不要。

## ラムダ式の利用

本人にとって今回が初めてのラムダ式。
```cpp
auto push = [&](ll e, ll n) mutable {
    if (dest[n] == -1) {
        dest[n] = dest[e] + 1;
        q.push(n);
    }
};
```
BFSの共通処理を1か所にまとめた。`[&]` による参照キャプチャなので `mutable` は不要。参照先が `const` なら `mutable` を付けても変更できない。

## 計算量

`M=10^d` とすると状態数は高々 M。各状態の遷移数は高々2つ。
整数の桁数計算を含めて時間 **O(M log M)**、距離配列・キューの空間 **O(M)**。
制約では十分小さい。

## 振り返り

**自力AC。** BFSの設計、状態数制限、回転計算、共通遷移をラムダにまとめる実装は自分で考えた。
対話で `mutable` が不要であること、`pow` の浮動小数点計算を整数累乗に変える改善余地が確認された。
今回のACコードは元の `mutable` と `pow` を維持して保存した。
