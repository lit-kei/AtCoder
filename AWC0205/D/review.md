# AWC0205 D — 接続容器の色配置

- [問題文](https://atcoder.jp/contests/awc0205/tasks/awc0205_d)
- [AC提出](https://atcoder.jp/contests/awc0205/submissions/80951698)
- 結果: **AC、400点、22:37**
- [main.cpp](main.cpp): 最終ACコード

## 考え方
交換できる容器を辺で結んだ無向グラフを考える。**同じ連結成分**内では、辺に沿う交換を繰り返して色を自由に並べ替えられる。一方、異なる連結成分の間では液体を移せない。

連結成分 \(i\) の大きさを \(c_i\)、赤色（`1`）の個数を \(r_i\) とすると、その成分の色配置の数は \(\binom{c_i}{r_i}\)。成分ごとの配置は独立なので、答えは

\[
\prod_i \binom{c_i}{r_i}\pmod{998244353}
\]

となる。

## 実装
- AtCoder Library の `dsu` で各辺の両端をマージする。
- `d.groups()` で連結成分を列挙し、頂点数と `1` の個数を調べる。
- `modint998244353` と階乗テーブルで \(\binom cr=c!/(r!(c-r)!)\) を求める。

## 計算量
- 時間: **O(N+Mα(N))**（階乗計算、Union-Find、成分列挙。modint除算は定数とみなす場合）
- 空間: **O(N)**

## メモ
当初「サイクル」単位で考えたが、必要なのは**連結成分**という観察。本人コメントでは `groups()` は調べて発見した API と記録。
