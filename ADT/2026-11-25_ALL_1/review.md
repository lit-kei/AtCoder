## F問題の振り返り

- 結果は配点順の走査に修正して AC。
- 現在の最高得点者は追加で解く必要がない。それ以外の参加者は、未正解の問題を配点の高い順に解き、現在の最高得点を超えるまでの問題数を数える。同じ問題数で得られる加点は、高い配点から選ぶと最大になる。

### 誤答の原因

配点と元の問題番号の組 `A` は昇順にソートしていたが、追加で解く問題を選ぶときは元の問題番号 `j` を逆順に走査していた。`A[indexes[j]].first` は元の `j` 番目の配点を取得するため、選択順は入力の逆順になっていた。

次の入力では、2人目は 1500 点の問題を1問解けば逆転できる。修正前は 500 → 500 → 1500 の順に選び、2人目の答えを `3` と出力した。正しくは `1`。

```text
2 3
1500 500 500
oxx
xxx
```

### 修正

ソート済みの `A` を末尾から直接走査する。組に保存した元の問題番号で正解済みかを判定し、未正解ならその配点を加える。`rest` は最高得点までの差なので、`rest < 0` になった時点で逆転できる。

```cpp
drep(j, M) {
    auto [p, index] = A[j];
    if (S[i][index] == 'o') continue;
    rest -= p;
    cnt++;
    if (rest < 0) break;
}
```
