# ABC254 D — Together Square

- 問題: https://atcoder.jp/contests/abc254/tasks/abc254_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 平方自由部分で分類・重複する平方因子の除去・数え上げ

## 着想

任意の正整数 a は一意に `a=s*u^2` と書ける。ただし s は平方自由数（1以外の平方数で割り切れない整数）。
二数 `a=s*u^2`, `b=t*v^2` について、積が平方数になることと `s=t` は同値。
平方自由部分が s の整数が `c_s` 個あれば、そのグループから順序付きで選ぶ方法は `c_s^2` 通り。
したがって答えは `sum_s c_s^2`。

## 本人の実装

```cpp
vc<bool> visited(N+1, false);
ll ans = 0;
nfor(i, 1, N + 1) {
    if (visited[i]) continue;
    ll j = 2;
    while (i * j * j <= N) {
        visited[i*j*j] = true;
        j++;
    }
    ans += (j-1)*(j-1);
}
```

i を昇順に見て、既に訪問済みならその i は何らかのより小さい平方自由数の平方倍である。
訪問していない i は平方自由であり、`i*1^2, i*2^2, ...` が同じ平方自由部分を持つ集合となる。
`j` が初めて `i*j*j > N` となったとき、グループの要素数は `j-1`。その二乗を答えに加える。
`i*1^2=i` 自体は visited にしないが、i を1回しか処理しないので問題ない。

## 正当性

平方自由部分による分割は一意なので、どの整数もただ一つのグループに属する。
各グループの平方自由部分 s はそのグループ内で最小の整数であるため、昇順走査時に visited[s] は false。
s で列挙した `s*j^2` は次回以降は visited として飛ばされる。
各条件を満たす順序付きペアは同一グループに含まれ、そのグループの寄与 `c_s^2` で一度だけ数えられる。

## 計算量

値の上限 N に対し、各 i の内部 while 反復数は高々 `floor(sqrt(N/i))-1`。
これを全 i で上から押さえると

```text
sum_{i=1}^N sqrt(N/i) = sqrt(N) * sum_{i=1}^N 1/sqrt(i) = O(N)
```

となる。外側の走査も O(N) なので、**時間 O(N)**、訪問配列 **空間 O(N)**。
なお、入力範囲なら `i*j*j` は評価時も long long の範囲で安全。
