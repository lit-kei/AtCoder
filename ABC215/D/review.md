# ABC215 D — Coprime 2

- 問題: https://atcoder.jp/contests/abc215/tasks/abc215_d
- 状態: AtCoder ProblemsでAC済みとの本人の報告。過去のコードを発見。
- 元コード: C++の簡素な旧テンプレート。最終提出との一致は未確認。
- 注意: 発見したコードには篩での範囲外アクセスがあるため、修正・再AC確認まで `main.cpp` は登録しない。

## 解法

1. エラトステネスの篩で素数を列挙。
2. 各 `A_i` の素因数を集合 `includedPrime` に集める。
3. `1..M` のうち、`includedPrime` 中のいずれかの素因数の倍数を除外。
4. 除外されなかった整数を出力。

全ての `A_i` と互いに素であることは、各 `A_i` に現れる素因数のどれでも割り切れないことと同値。条件を満たす整数を直接探す代わりに、満たさない整数を除外する篩の応用。

## 元コードの注意点

```cpp
vector<bool> furui(100000, false);
// ...
for (int j = 1; j <= 100000 / i; j++)
    furui[i*j] = true;
```

`i=2,j=50000` で `furui[100000]` にアクセスし、範囲外。未定義動作。配列を `100001` にするか、添字を配列範囲内に収める必要がある。

各 `A_i` の素因数分解で全素数（約9592個）を調べる可能性があり、最悪で約 `O(N π(10^5))` の剰余演算が発生する。 `p*p > e` で打ち切り、残った `e>1` を素因数として扱えば高速化できる。

篩部分は `O(V log log V)`（`V=10^5`）。除外の倍数走査は `O(M sum_{p included}1/p)` で、高々 `O(M log log M)` 程度に抑えられる。
