# ABC230 D — Destroyer Takahashi

- 問題: https://atcoder.jp/contests/abc230/tasks/abc230_d
- 結果: **自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 右端順ソート・貪欲法・`set` による削除

## 解法

各壁を区間 `[L_i,R_i]` で表す。右端 `R_i` の昇順に壁を調べる。

まだ壊されていない壁 `i` を見つけたら、長さ `D` の攻撃範囲を `[R_i,R_i+D-1]` として攻撃する。
この攻撃で破壊される壁をまとめて除外する。壁の左端を `set<pair<ll,ll>> L` に `{L_i,i}` で保持し、`L_i <= R_i + D - 1` の壁を先頭から `erase` する。破壊済みフラグにより、その後の処理をスキップする。

## 正当性

今残っている壁で、右端最小の壁 `i` は必ず攻撃で壊す必要がある。
これを壊す攻撃範囲が `[p,p+D-1]` なら `p <= R_i` かつ `p+D-1 >= L_i`。
攻撃開始位置を `R_i` まで右に動かしても、他の残存壁で元の攻撃が届いたものは壊せる。
なぜなら残存壁 `j` は必ず `R_j >= R_i` であり、元の攻撃が届いていたなら `L_j <= p+D-1 <= R_i+D-1` だから。
したがって `[R_i,R_i+D-1]` を選ぶ最適解が存在し、貪欲に繰り返してよい。

## 計算量

`R` のソート: O(N log N)。
`set` 初期化: O(N log N)。
各壁は `set` から高々1回削除されるので、全 `while` の削除処理の合計が O(N log N)。`destroyed` によってスキップする判定は O(N)。
**時間 O(N log N)、空間 O(N)**。

## 振り返り

**自力AC。** 「DPで似た問題を見た」「攻撃開始位置 x は R_i でよい」「貪欲法で解ける」と考え、右端順に処理する方針に到達した。
未破壊の壁を左端順にも `set` で管理することで、今回の攻撃範囲に届く壁を効率的に削除する実装にした。

改善余地: この問題は `set` を使わず、右端順にソートして「最後の攻撃が届く最右位置」だけを持つことでも O(N log N) で解ける。
