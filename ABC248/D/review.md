# ABC248 D — Range Count Query

- 問題: https://atcoder.jp/contests/abc248/tasks/abc248_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 値ごとの出現位置配列 + 二分探索

## 解法

`S[x]` に値 `x+1` が現れる **0-indexed の位置**を昇順に保存する。
クエリ `L,R,X` について、まず 0-indexed に変換する。
値 `X` の出現位置配列を `S[X-1]` とすると、区間 `[L,R]` 内の出現数は

```cpp
upper_bound(S[X].begin(), S[X].end(), R) -
lower_bound(S[X].begin(), S[X].end(), L)
```

で求まる（ここで X は既に1減じた0-indexedの値）。
`lower_bound` は L 以上の最初の位置、`upper_bound` は R より大きい最初の位置を指すので、差が求める個数。

## 正当性

S[x] は値 x+1 が現れる位置を過不足なく記録する。
区間内にある出現位置は、ソートされた S[x] 上で L 以上・R 以下の連続した部分区間になる。両境界のイテレータの差はその要素数と一致する。

## 計算量

本人のACコードは S の各配列を sort するため、前処理が高々 O(N log N)、1クエリが O(log N)、合計 **O(N log N + Q log N)**。空間は **O(N)**。

ただし、`i=0,1,...,N-1` の順に位置を push_back しているため、S[x] は**最初から昇順**。sort は不要で、省略すれば時間 **O(N + Q log N)** になる。

## 自力と振り返り

**完全自力AC**。値ごとに出現位置を保存し、二分探索2回の差で区間内の個数を計算する方法を自力で実装した。
AC後に、位置配列が構築時点でソート済みであることを確認した。
