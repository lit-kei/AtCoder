# ABC250 D — 250-like Number

- 問題: https://atcoder.jp/contests/abc250/tasks/abc250_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: エラトステネスの篩 + 素数計数関数の累積和

## 着想

数えるべき整数は、異なる素数 p<q に対し `p*q^3 <= N` を満たす積 `p*q^3`。
q を固定すると必要な p は

```text
p <= min(q-1, floor(N/q^3))
```

を満たす素数である。

`prime[x]` を x 以下の素数の個数（素数計数関数 π(x)）として累積計算しておけば、
各素数 q に対する選択肢は

```text
prime[min(q-1, N/(q*q*q))]
```

個。これらを全素数 q について足せばよい。
異なる (p,q) は異なる整数 p*q^3 に対応するため重複計数しない。

## 本人の実装

`mx=cbrt(N)` までエラトステネスの篩で素数を判定。
`prime[i]=prime[i-1]` をまず行い、i が素数なら `prime[i]++` し、i の倍数を合成数としてマークする。
素数 q=i の場合に `p=min(i-1,N/(i*i*i))` として `ans += prime[p]` とする。
`p` はここでは候補の素数そのものではなく、その上限値を表す変数である。

## 正当性

任意の条件を満たすペア (p,q) について、q は素数かつ q^3 <= N なので q <= floor(cuberoot(N))。
その q で必要な p は q 未満かつ N/q^3 以下の素数すべてであり、その数が前述の prime の値と一致する。
どのペアも一意に対応する q の反復でちょうど1回数えられる。

## 計算量

M=floor(cuberoot(N)) とする。
篩 O(M log log M)、素数の累積個数計算と数え上げ O(M)。
時間 **O(M log log M)**、空間 **O(M)**。

## 注意点・改善

`cbrt` は浮動小数点数を返すため、整数変換時に境界がずれる可能性がある。一般に厳密な境界が必要なら整数演算で補正する。
`furui[0]`, `furui[1]` は true のままでも、i を2から走査しているので今回の答えに影響しない。
篩は `j=i*i` から始めてもよい（ただし十分広い型と範囲に注意）。

## 自力と振り返り

**完全自力AC**。q を固定した不等式の変形、素数の個数を累積和でまとめる方針、篩と集計を本人が独力で実装した。
