# ABC252 D — Distinct Trio

- 問題: https://atcoder.jp/contests/abc252/tasks/abc252_d
- 結果: **完全自力AC**（本人確認）
- コード: [main.cpp](main.cpp)
- 手法: 出現頻度と組合せの漸化式（累積的な数え上げ）

## 方針

異なる3つの値を持つ添字の組を数える。値ごとの出現回数を `freq[v]` とすると、異なる値3種類 `u<v<w` を固定したときの選び方は `freq[u]*freq[v]*freq[w]`。

これを全ての値の三重ループで数えず、値を昇順に追加しながら、1種類・2種類・3種類の組合せ数を管理する。

- `sum`: 既に処理した値から1個選ぶ方法の総数
- `pattern`: 既に処理した値から異なる2種類を1個ずつ選ぶ方法の総数
- `ans`: 既に処理した値から異なる3種類を1個ずつ選ぶ方法の総数

次の値の出現回数が e なら、

```cpp
ans += pattern * e;
pattern += sum * e;
sum += e;
```

と更新できる。各変数は**新しい値を含める前**の下位段階の組合せ数を使うので、3種類→2種類→1種類の順で更新する。

## 正当性

新しく処理する値を含まない組は以前のカウントに残る。
新しい値を含む3種類の組は、以前の異なる2種類の組と新しい値の出現箇所の組合せで `pattern*e` 通り。
同様に2種類の新規組は `sum*e` 通り、1種類の新規組は e 通り。
したがって更新後も各変数が正しい組合せ数を表す。

## 計算量

値域の大きさ M=200000、入力長 N とすると、頻度表の構築 O(N)、値域の一巡 O(M)。
時間 **O(N+M)**、空間 **O(M)**。

## 一般化

`dp[k]` を「異なる値を k 種類選ぶ組の数」とすると、出現回数 e の値を追加する際には

```cpp
for (int k = K; k >= 1; --k) dp[k] += dp[k-1] * e;
```

と更新できる（`dp[0]=1`）。今回の `sum, pattern, ans` は K=3 の場合を直接変数で表したもの。

## 自力と振り返り

**完全自力AC。** 頻度集計、2種類の組合せ数 `pattern`、3種類の組合せ数 `ans` の漸化式、更新順序、実装まで自力で完成させた。
