# ABC485 A — Same Side

- [問題文](https://atcoder.jp/contests/abc485/tasks/abc485_a)
- 結果: **AC、100点、1:00、WAなし**
- [main.cpp](main.cpp): コンテスト中のACコード

## 解法

家の座標が 0 なので、スーパーと駅が同じ方向にあるのは、\(A\) と \(B\) がともに正、またはともに負のとき。

制約で \(A\neq0\), \(B\neq0\) が保証されているため、**\(A\times B>0\)** なら `Yes`、それ以外なら `No` を出力する。

## 計算量

- 時間: **O(1)**
- 空間: **O(1)**

## 振り返り

積の符号だけで場合分けを一本化できた。\(|A|,|B|\le 100\) なので `ll` での積のオーバーフローも問題にならない。
