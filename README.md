# AtCoder

AtCoderの解答コードと、コンテスト中の考察メモ・振り返りを記録するリポジトリです。

## 保存方針

- `ABC483/D/`、`AGC079/A/` のように、コンテストと問題ごとに整理する
- `main.cpp`：AC確認済みの最終解法（会話から整理する場合は未使用テンプレートを省くことがあります）
- `memo.txt`：途中の着想、失敗、気づき。短いD問題などでは省略可
- `review.md`：解法、計算量、自力で思いついた点、ヒントを受けた点、振り返り
- 未AC・未確認の場合、`main.cpp` は原則保留し、状態を `review.md` に明記する
- 解法はすぐに教わらず、対話と段階的なヒントを使って自力ACを目指す
