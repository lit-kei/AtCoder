## 解法

x 個のプロジェクトを作れるか判定する。
1部署は各プロジェクトに高々1人しか出せないので、部署 i から参加可能な人数は高々 min(A_i,x)。
ゆえに必要条件は

```math
\sum_{i=1}^{N}\min(A_i,x)\ge Kx.
```

これは十分条件でもある。各部署から使う人数 b_i を 0 <= b_i <= x、総和 Kx に選べる。
残り r 個のプロジェクトを作る時、各部署の残員 b_i <= r、合計 Kr を不変条件とする。
残員が r の部署は高々 K 個（そうでなければ合計が Kr を超える）。
よって残員の多い部署から異なる K 部署を選び各1人減らせば、残員は全て r-1 以下、合計 K(r-1) になる。
帰納的に x 個分の割り当てが構成できる。

そこで判定関数 `check(x)` にて `sum min(A_i,x) >= K*x` を調べる。
x 個作れるなら x-1 個も作れるので判定は単調。
`ok=0` を可能、`ng=floor(S/K)+1` を不可能として二分探索し最大可能数を答える。

## 計算量

`check(x)` は O(N)。
`S=sum(A_i)` とすると、二分探索は O(log(S/K+1)) 回。
時間 **O(N log(S/K+1))**、空間 **O(N)**。
