ABC227 D — Project Planning (AC)

当初の独立した考察:
- min_i A_i <= ans <= floor(sum_i A_i / K)
- 部署が異なる必要があるので、単純な人数順のシミュレーションだけでは難しい。
- A_i が最大 10^12 で、個別プロジェクトの構成をシミュレーションするのは非現実的。
- x 個作るとき、どの部署も使用人数は x 以下、総使用人数 Kx。
- その人数条件を満たすなら割り当てが存在するのでは、という予想を立てた。

対話で検討したこと:
- x 個のプロジェクトを作れるか、という判定問題に分離。
- 判定式 sum_i min(A_i,x) >= K*x はアシスタントから提示された。
- その十分性の根拠として、本人が「まだ使っていない人の多い部署から順に割り当てる」貪欲法を提案。
- アシスタントが帰納的不変条件で証明を補助。残り r 件に対し使用可能残人数 b_i <= r、総和 Kr が維持される。
- 実現可能性の単調性に基づき、本人が境界 ok=0、ng=S/K+1 の二分探索を自分で実装。

最終結果: AC（本人確認）。
青diff。着想の核は自力だが、判定式と厳密な証明にはヒントあり。
